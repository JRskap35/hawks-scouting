# Hawks Scouting

Player search for the Boise Hawks scouting staff, built for 2027 signings.

**[Open the site](https://jrskap35.github.io/hawks-scouting/)**

The site shows made up demo players until the database is connected.

## What's in here

| Folder | What it is |
| --- | --- |
| `web/` | The website |
| `scrapers/` | Pulls Pioneer League stats, rosters, and transactions |
| `db/` | Database tables and login rules |
| `.github/workflows/` | Publishes the site and refreshes the data every two weeks |

Setup steps are in [docs/SETUP.md](docs/SETUP.md).
